欢迎来到 Chipaper 的演示站。这里没有大幅背景图，也没有复杂的卡片墙；打开页面，首先看到的就是文字。

## 从阅读开始

这个主题保留了我们喜欢的博客样子：一段简单的自我介绍，按时间排列的文章，以及不抢走注意力的导航。

你可以点击右上角的月亮或太阳切换配色，也可以打开归档和标签，看看文章多起来之后的样子。

## 为中文留一点空间

中文、英文和代码经常出现在同一段里。比如，在 HomeLab 中运行 Hugo，用 GitHub Actions 自动部署，或者在 Linux 终端里查一条日志。

Chipaper 使用 Google Sans Code 搭配更纱等宽黑体，并对中文行距、标点和窄屏换行做了适配。它们保留各自的原始字宽，不强行把所有内容排成字符网格。

> A quiet place for words, code, and ordinary days.

## 写一篇文章

把 Markdown 文件放进 `content/posts/`，写上标题和日期，再启动 Hugo 就可以预览。

```yaml
---
title: "今天又折腾了点什么"
date: 2026-11-05T12:00:00+08:00
tags: ["日常", "开发"]
---
```
