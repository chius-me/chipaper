这是 Chipaper 的演示站。首页是一段介绍，下面按时间排文章。右上角的月亮或太阳用来换浅色和深色。

点页头的语言菜单，可以直接切到这篇文章的繁体中文或英文版。

文章多了以后，归档和标签还在原来的地方。

中文和英文经常出现在同一句里。比如在 HomeLab 里跑 Hugo，用 GitHub Actions 部署，或者在终端里翻一条日志。主题用 Google Sans Code 配更纱等宽黑体，中文的行距和窄屏时的换行单独调过。

## 一篇文章长这样

把 Markdown 放进 `content/posts/`，写上标题和日期，Hugo 起来就能看。

```yaml
---
title: "今天又折腾了点什么"
date: 2026-11-05T12:00:00+08:00
tags: ["日常", "开发"]
---
```

旁边有一页[排版](../typography/)，还有[怎么装](../getting-started/)。
