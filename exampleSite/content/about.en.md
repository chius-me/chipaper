I wrote Chipaper for [my own blog](https://chius.cc/) and later packaged it as a Hugo theme anyone can install. The single-column layout takes cues from [AstroPaper](https://github.com/satnaing/astro-paper) and [Archie](https://github.com/athul/archie).

English text and code use **Google Sans Code**, and Chinese text uses **Sarasa Mono SC**. The theme ships with both fonts and serves them with the site.

The demo posts show how mixed Chinese and English text, code blocks, and tables look. Installation instructions are in the repository.
